# 光年数智宣传片 V4

V4 作为 V5 的画面片源与可编辑工程保留。当前官网已改用 V5，画面保持不变，旧的程序合成配乐与转场音已停用；最新音轨工程见 `../studio-film-v5/`。以下为 V4 的制作与当时验证记录。

- 64 秒，1920×1080，30fps，H.264 / AAC 48kHz 双声道。
- 首镜头：NASA Blue Marble 地表与真实云层合成纹理，球面光照、大气边缘与低密度科技轨道。影像为历史合成，非实时气象；不代表 NASA 背书。
- 内容与数据来源见 `spec.json`；地球纹理来源、摘要及处理方法见 `assets/earth/sources.json`。
- 旧版无配乐试片已清理；正式有声/无声成片请使用 V5。
- 音乐与转场音为本工程原创程序合成，无第三方歌曲或声音样本。没有旁白，画面文字可独立讲述内容。

## 重建与编辑

在项目根目录运行，需要 Node 24、macOS Google Chrome、FFmpeg 8。脚本复用 V3 的管线，V4 的分镜、截图、地球渲染与成片独立保存，不引入官网运行依赖。

```sh
node video/studio-film-v4/audio.mjs
node video/studio-film-v4/render.mjs stills 45 120 165
node video/studio-film-v4/render.mjs render
node video/studio-film-v4/render.mjs serve
```

`serve` 输出本机编辑预览地址，可播放、拖动时间线。`scene.js` 管理镜头和字卡，`earth.js` 管理地球材质与光照，`spec.json` 管理内容及来源。音轨与中间视觉主文件由脚本生成并已忽略；截图冻结于当前版本。

## 制作时自检

临时测试脚本、QA 记录、抽帧与中间音轨已按要求清理；下列为制作时的结果摘要。原始素材及生成脚本保留，可按需重建。

- P/F/D：行业背景、四类服务、真实官网、工程方法和长期愿景均出现在对应镜头；未虚构客户、收入、团队、专利或交易成绩。
- Q：首镜头 f45/f120/f165 及成片 f120 已实际查看；4096×2048 地表、2048×1024 云层、1536px 球面渲染。修正前后保持 16:9 和相同镜头时长，不再使用线框球。
- R/B：品牌收尾落定超过 4 秒；无震屏或频繁全屏闪光；其余镜头沿用已抽帧自检的 V3。当时已核对成片联系表。
- A：完整解码两版通过；无削波，已测管线音画偏移为 0 samples；当时已完成音频参数回测。尚未做人工听感审阅，不宣称配乐审美或独立第三方终检通过。
- 官网：76 项既有测试通过，25 页 SSG 构建通过；隔离 Chromium 实际点击检查覆盖桌面 1440px、窄屏 375/320px、有声导航播放、静音回退、点击解锁、减少动态效果和原生音量操作。
- Safari / iOS / Android 实机、线上部署及真实扬声器听感未验证。

关于页先尝试有声播放。直接访问而无用户激活时，浏览器可能拒绝声音；此时先静音播放并显示“开启声音”。通过真实点击导航进入时已在 Chromium 验证有声自动播放，不使用绕过浏览器策略的手段。减少动态效果设置优先，不自动播放。
